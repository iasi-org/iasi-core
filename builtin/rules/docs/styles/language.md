# Document language

## Metadata

| Field | Value |
|---|---|
| ID | docs.styles.language |
| Description | Preserves the established language of a document. |
| Scope | docs |
| Level | must |
| Tags | docs; style; language; consistency |

## Rule

The language established by the target document must be preserved. When a new document has no established language, the project configuration or explicit task context determines the language.

## Exceptions

None.

## Rationale

Language consistency is part of the document contract and avoids fragmented editorial voice.
