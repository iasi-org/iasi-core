# Terminology consistency

## Metadata

| Field | Value |
|---|---|
| ID | docs.styles.terminology |
| Description | Keeps terminology stable throughout a document. |
| Scope | docs |
| Level | must |
| Tags | docs; style; terminology; semantics |

## Rule

The same concept must use the same canonical term throughout a document unless a distinction is intentional and explained.

## Exceptions

None.

## Rationale

Terminological stability reduces semantic ambiguity and prevents readers from inferring distinctions that do not exist.
