# Concept before dependent terminology

## Metadata

| Field | Value |
|---|---|
| ID | docs.styles.concept-before-dependent-term |
| Description | Introduces concepts before using terminology that depends on them. |
| Scope | docs |
| Level | should |
| Tags | docs; style; structure; terminology; pedagogy |

## Rule

A concept should be introduced before the document relies on terminology, abbreviations, or conclusions that require that concept to be understood.

## Exceptions

None.

## Rationale

Readers should not need information that the document has not yet supplied.
