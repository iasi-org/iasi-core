# Cohesive paragraphs

## Metadata

| Field | Value |
|---|---|
| ID | docs.styles.cohesive-paragraphs |
| Description | Keeps related ideas together when they form one argument. |
| Scope | docs |
| Level | should |
| Tags | docs; style; paragraphs; prose; cohesion |

## Rule

Related ideas that form one line of reasoning should be developed within cohesive paragraphs rather than fragmented into successive isolated sentences.

## Exceptions

None.

## Rationale

Cohesive prose preserves argumentative continuity and reduces artificial visual fragmentation.
