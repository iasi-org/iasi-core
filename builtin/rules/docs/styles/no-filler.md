# No filler

## Metadata

| Field | Value |
|---|---|
| ID | docs.styles.no-filler |
| Description | Requires sentences to carry useful information. |
| Scope | docs |
| Level | must-not |
| Tags | docs; style; prose; concision; filler |

## Rule

Documentation must not add filler, repeated conclusions, inflated language, or generic statements solely to increase length or apparent completeness.

## Exceptions

None.

## Rationale

Technical documentation is stronger when every sentence advances explanation, evidence, decision, or context.
