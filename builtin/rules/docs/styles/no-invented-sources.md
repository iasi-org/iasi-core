# No invented sources

## Metadata

| Field | Value |
|---|---|
| ID | docs.styles.no-invented-sources |
| Description | Forbids fabricated quotations, references, and attributions. |
| Scope | docs |
| Level | must-not |
| Tags | docs; style; sources; citations; integrity |

## Rule

Documentation must not fabricate quotations, references, citations, authors, dates, titles, or attributions.

## Exceptions

None.

## Rationale

Invented provenance corrupts the evidence chain and makes otherwise valid content untrustworthy.
