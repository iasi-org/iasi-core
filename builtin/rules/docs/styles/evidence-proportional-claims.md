# Claims match evidence

## Metadata

| Field | Value |
|---|---|
| ID | docs.styles.evidence-proportional-claims |
| Description | Keeps claims proportional to available evidence. |
| Scope | docs |
| Level | must |
| Tags | docs; style; evidence; claims; accuracy |

## Rule

Claims must be proportional to the evidence available in the project or explicitly cited sources. Uncertainty must not be converted into certainty through wording.

## Exceptions

None.

## Rationale

Editorial confidence must reflect evidential confidence.
