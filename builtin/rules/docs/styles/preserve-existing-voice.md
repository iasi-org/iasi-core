# Preserve existing voice

## Metadata

| Field | Value |
|---|---|
| ID | docs.styles.preserve-existing-voice |
| Description | Preserves the established voice when editing existing material. |
| Scope | docs |
| Level | should |
| Tags | docs; style; voice; editing |

## Rule

When editing an existing document, new or changed prose should preserve its established voice unless the task explicitly changes the editorial style.

## Exceptions

None.

## Rationale

A document should read as one coherent work rather than a collage of different authorial voices.
