# Lists for parallel items

## Metadata

| Field | Value |
|---|---|
| ID | docs.styles.lists-for-parallel-items |
| Description | Uses lists only when items are genuinely parallel or sequential. |
| Scope | docs |
| Level | should |
| Tags | docs; style; lists; structure |

## Rule

Lists should be used when their items are genuinely parallel, independent, or sequential. Related argumentative ideas should normally remain prose.

## Exceptions

None.

## Rationale

A list should expose structure that already exists in the content, not manufacture structure for decoration.
