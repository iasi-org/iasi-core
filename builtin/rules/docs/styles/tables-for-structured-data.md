# Tables for structured data

## Metadata

| Field | Value |
|---|---|
| ID | docs.styles.tables-for-structured-data |
| Description | Uses tables when structure or comparison benefits from columns. |
| Scope | docs |
| Level | should |
| Tags | docs; style; tables; structure; comparison |

## Rule

A table should be used when structured attributes or comparisons are clearer in rows and columns than in ordinary prose.

## Exceptions

None.

## Rationale

Tables are valuable when relationships are inherently tabular, but they impede reading when used for narrative content.
