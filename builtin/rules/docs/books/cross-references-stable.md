# Stable cross references

## Metadata

| Field | Value |
|---|---|
| ID | docs.books.cross-references-stable |
| Description | Uses semantic references instead of fragile positional references. |
| Scope | docs/books |
| Level | should |
| Tags | docs; books; cross-references; identifiers; stability |

## Rule

Cross references should use stable semantic identifiers provided by the publishing system rather than hard-coded page numbers, chapter numbers, or other positional values.

## Exceptions

None.

## Rationale

Semantic references survive reordering and repagination.
