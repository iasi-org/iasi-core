# Chapter sequence

## Metadata

| Field | Value |
|---|---|
| ID | docs.books.chapter-sequence |
| Description | Requires chapter order to reflect conceptual dependency or narrative progression. |
| Scope | docs/books |
| Level | should |
| Tags | docs; books; structure; chapters; sequence |

## Rule

Book chapters should be ordered so that concepts, dependencies, and decisions appear before material that relies on them.

## Exceptions

None.

## Rationale

A good chapter sequence reduces forward references and lets understanding accumulate progressively.
