# Purposeful code examples

## Metadata

| Field | Value |
|---|---|
| ID | docs.books.code-examples-purposeful |
| Description | Requires code examples to demonstrate a concrete concept or consequence. |
| Scope | docs/books |
| Level | should |
| Tags | docs; books; code; examples; pedagogy |

## Rule

A code example should exist to clarify a concept, decision, behavior, or consequence. Examples should contain only the detail needed for that purpose unless completeness is itself the lesson.

## Exceptions

None.

## Rationale

Focused examples reduce incidental complexity and make the intended lesson visible.
