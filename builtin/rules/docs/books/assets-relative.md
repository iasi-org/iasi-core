# Relative book assets

## Metadata

| Field | Value |
|---|---|
| ID | docs.books.assets-relative |
| Description | Keeps book asset references portable within the project. |
| Scope | docs/books |
| Level | should |
| Tags | docs; books; assets; paths; portability |

## Rule

Book source files should reference project-owned assets using stable project-relative paths rather than machine-specific absolute paths.

## Exceptions

None.

## Rationale

Relative asset references keep the book portable across workstations, CI systems, and publication environments.
