# Generated output is not source

## Metadata

| Field | Value |
|---|---|
| ID | docs.books.generated-output-not-source |
| Description | Separates generated publication artifacts from editable source material. |
| Scope | docs/books |
| Level | must |
| Tags | docs; books; generated; source; publishing |

## Rule

Generated HTML, PDF, EPUB, DOCX, ODT, or other publication output must not become the canonical editable source when a source representation exists.

## Exceptions

None.

## Rationale

Keeping source and generated output distinct preserves reproducibility and prevents divergent edits.
