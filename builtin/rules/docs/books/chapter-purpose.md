# Chapter purpose

## Metadata

| Field | Value |
|---|---|
| ID | docs.books.chapter-purpose |
| Description | Requires each book chapter to have a clear purpose in the book narrative. |
| Scope | docs/books |
| Level | should |
| Tags | docs; books; structure; chapters; purpose |

## Rule

Each chapter should have a clear purpose and contribute a distinct step to the book's overall argument, explanation, or progression.

## Exceptions

None.

## Rationale

A chapter is an editorial unit, not merely a container for material that happened to accumulate together.
