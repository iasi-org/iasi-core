# No manual heading numbering

## Metadata

| Field | Value |
|---|---|
| ID | docs.books.no-manual-numbering |
| Description | Keeps structural numbering separate from heading text. |
| Scope | docs/books |
| Level | should |
| Tags | docs; books; headings; numbering; publishing |

## Rule

Chapter, part, section, figure, table, and listing numbers should be generated by the publishing system when the system supports numbering. Numbers should not be embedded manually in titles solely for presentation.

## Exceptions

Manual numbering may be used when the target publishing system cannot generate the required numbering or when the number is semantically part of the title.

## Rationale

Generated numbering remains correct when content is inserted, removed, or reordered.
