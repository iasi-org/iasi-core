# Function docstrings describe the contract

## Metadata

| Field | Value |
|---|---|
| ID | coding.styles.python.docstring-contract |
| Description | Documents externally relevant function behavior. |
| Scope | coding/python |
| Level | should |
| Tags | coding; python; style; documentation; docstrings; contract |

## Rule

A non-trivial public function or method docstring should document applicable arguments, return values, side effects, raised exceptions, and calling restrictions.

## Exceptions

Information that is already unambiguous from a concise signature and type annotations need not be repeated mechanically.

## Rationale

Useful documentation describes the contract rather than restating syntax.
