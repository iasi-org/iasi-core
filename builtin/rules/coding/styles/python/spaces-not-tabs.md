# Spaces instead of tabs

## Metadata

| Field | Value |
|---|---|
| ID | coding.styles.python.spaces-not-tabs |
| Description | Uses spaces rather than tabs for Python indentation. |
| Scope | coding/python |
| Level | must |
| Tags | coding; python; style; formatting; indentation; spaces |

## Rule

Python indentation must use spaces, not tabs.

## Exceptions

A legacy file already consistently indented with tabs may retain tabs until it is deliberately normalized.

## Rationale

Python forbids mixing tabs and spaces and PEP 8 prefers spaces.

## Sources

PEP 8 - Style Guide for Python Code: https://peps.python.org/pep-0008/
