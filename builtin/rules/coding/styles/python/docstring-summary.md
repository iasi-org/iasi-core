# Docstring summary line

## Metadata

| Field | Value |
|---|---|
| ID | coding.styles.python.docstring-summary |
| Description | Starts docstrings with a concise summary. |
| Scope | coding/python |
| Level | must |
| Tags | coding; python; style; documentation; docstrings |

## Rule

Every docstring must begin with a concise one-line summary. A multi-line docstring must place a blank line between the summary and the detailed description.

## Exceptions

None.

## Rationale

The summary can be consumed by indexing and documentation tools and lets readers understand the API quickly.

## Sources

PEP 257 - Docstring Conventions: https://peps.python.org/pep-0257/
