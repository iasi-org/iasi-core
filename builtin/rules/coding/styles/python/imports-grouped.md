# Grouped imports

## Metadata

| Field | Value |
|---|---|
| ID | coding.styles.python.imports-grouped |
| Description | Groups imports by origin. |
| Scope | coding/python |
| Level | must |
| Tags | coding; python; style; imports; organization |

## Rule

Imports must be grouped in this order: standard library, third-party dependencies, then local application or library imports. Groups must be separated by a blank line.

## Exceptions

None.

## Rationale

Grouping reveals dependency boundaries at a glance.

## Sources

PEP 8 - Style Guide for Python Code: https://peps.python.org/pep-0008/
