# No trailing whitespace

## Metadata

| Field | Value |
|---|---|
| ID | coding.styles.python.trailing-whitespace |
| Description | Removes invisible trailing whitespace. |
| Scope | coding/python |
| Level | must-not |
| Tags | coding; python; style; whitespace; formatting |

## Rule

Python source lines must not contain trailing whitespace.

## Exceptions

None.

## Rationale

Trailing whitespace is invisible noise and can alter backslash-continuation behavior.

## Sources

PEP 8 - Style Guide for Python Code: https://peps.python.org/pep-0008/

## Examples

None.
