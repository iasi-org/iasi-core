# Closing brace placement

## Metadata

| Field | Value |
|---|---|
| ID | coding.styles.generic.block-closing-brace |
| Description | Places closing braces on their own line. |
| Scope | coding |
| Level | must |
| Tags | coding; style; formatting; blocks; braces |

## Rule

When a language uses `}` to close a block, the closing brace must appear on a line by itself, aligned with the construct that owns the block.

## Exceptions

None.

## Rationale

A closing delimiter on its own line makes the end of a block immediately visible.
