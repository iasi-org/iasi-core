# Comments explain intent

## Metadata

| Field | Value |
|---|---|
| ID | coding.styles.generic.comments-explain-why |
| Description | Uses comments for intent, constraints, and non-obvious decisions. |
| Scope | coding |
| Level | should |
| Tags | coding; style; comments; readability |

## Rule

Comments should explain intent, constraints, tradeoffs, or non-obvious decisions. They should not merely translate the code into prose.

## Exceptions

None.

## Rationale

Comments are most useful when they preserve information that cannot be recovered directly from the implementation.
