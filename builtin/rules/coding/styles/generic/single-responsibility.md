# Single responsibility

## Metadata

| Field | Value |
|---|---|
| ID | coding.styles.generic.single-responsibility |
| Description | Keeps each function or method focused on one operation or decision. |
| Scope | coding |
| Level | should |
| Tags | coding; style; functions; methods; responsibility |

## Rule

A function or method should have one clear responsibility. When several independent operations are visible in one function, they should be separated unless keeping them together materially improves clarity.

## Exceptions

None.

## Rationale

Focused operations are easier to name, test, compose, replace, and reason about.
