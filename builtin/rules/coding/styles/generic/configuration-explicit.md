# Configuration is explicit

## Metadata

| Field | Value |
|---|---|
| ID | coding.styles.generic.configuration-explicit |
| Description | Keeps configurable behavior visible and discoverable. |
| Scope | coding |
| Level | should |
| Tags | coding; style; configuration; discoverability |

## Rule

Configuration that changes program behavior should be explicit, discoverable, and located where a maintainer can reasonably expect to find it. Hidden configuration and unexplained implicit defaults should be avoided.

## Exceptions

None.

## Rationale

Explicit configuration reduces accidental behavior and makes operational decisions inspectable.
