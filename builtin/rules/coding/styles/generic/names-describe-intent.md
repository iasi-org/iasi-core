# Names describe intent

## Metadata

| Field | Value |
|---|---|
| ID | coding.styles.generic.names-describe-intent |
| Description | Requires names to describe purpose rather than incidental implementation details. |
| Scope | coding |
| Level | should |
| Tags | coding; style; naming; readability |

## Rule

Names should communicate the role or intention of the element they identify. Names based only on temporary implementation details, arbitrary abbreviations, or accidental mechanics should be avoided.

## Exceptions

None.

## Rationale

Intent-oriented names reduce the amount of implementation code that must be inspected to understand a program.
