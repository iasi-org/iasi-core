# Smallest clear implementation

## Metadata

| Field | Value |
|---|---|
| ID | coding.styles.generic.smallest-clear-implementation |
| Description | Prefers the smallest implementation that clearly satisfies the requirement. |
| Scope | coding |
| Level | should |
| Tags | coding; style; simplicity; implementation |

## Rule

The implementation should contain only the structure necessary to satisfy the current requirement clearly and correctly.

## Exceptions

None.

## Rationale

Smaller implementations have fewer moving parts, are easier to understand, and reduce accidental maintenance cost.
