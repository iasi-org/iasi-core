## Rule

Java code must use conventional Java casing: classes, records, interfaces, enums, and annotations use `UpperCamelCase`; methods, local variables, parameters, and fields use `lowerCamelCase`; constants use `UPPER_SNAKE_CASE`; package names use lowercase.

## Exceptions

None.

## Rationale

Conventional Java naming makes code immediately legible to Java developers and compatible with the surrounding ecosystem.
