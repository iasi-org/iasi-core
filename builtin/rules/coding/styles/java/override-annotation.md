# Override annotation

## Metadata

| Field | Value |
|---|---|
| ID | coding.styles.java.override-annotation |
| Description | Marks Java overrides explicitly. |
| Scope | coding/java |
| Level | must |
| Tags | coding; java; style; override; annotations |

## Rule

A Java method that overrides or implements an inherited method must use `@Override`.

## Exceptions

None.

## Rationale

The annotation makes intent explicit and lets the compiler detect signature mistakes.
